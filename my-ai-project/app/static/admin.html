บัญชี Cloud Run ต้องมีสิทธิ์ Firestore และ Google Sheets API พร้อมกับถูกแชร์เข้าถึงไฟล์ชีตนั้น การบันทึกค่าชีตยังไม่เริ่มอ่านชีต ซิงก์ หรือแก้ไขแค็ตตาล็อก
SECRET MANAGER

ตั้งค่า Gemini API Key

เพื่อความปลอดภัย ไม่รับหรือแสดง API key ในหน้าเว็บนี้

  1. เปิด Google Cloud Console → Secret Manager
  2. สร้างหรืออัปเดต secret ชื่อ GEMINI_API_KEY
  3. ผูก secret เป็น environment variable ชื่อเดียวกันใน Cloud Run service
  4. สร้าง revision/deploy ใหม่ แล้วกลับมาตรวจสถานะด้านบน
ห้ามใส่ key ใน Firestore, GitHub, ช่องแชต หรือไฟล์ frontend
